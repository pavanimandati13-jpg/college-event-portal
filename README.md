# 🎓 CampusFest 2026 – College Event Portal

## 📌 Project Introduction

**CampusFest 2026 – College Event Portal** is a responsive web application designed to provide students with an easy way to view and register for college events.

The portal displays upcoming events, event details, registration forms, a photo gallery, and college contact information. It is designed with a clean and user-friendly interface that works on desktop, tablet, and mobile devices.

## 🚀 How to Run Locally

1. Download or clone the repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. The website will open in your browser.

## 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

The navigation, event cards, registration form, gallery, and contact section adjust according to the screen size.

---

## 📝 Registration

Students can enter their:

* Name
* Email
* Phone number
* Department
* Selected event
* Message

The form performs basic validation using JavaScript before displaying a registration success message.

> **Note:** The current version is a front-end project. Registration details are not stored in a database or sent to a server.
